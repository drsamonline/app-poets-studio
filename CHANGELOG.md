# Changelog — app-poets-studio

Newest first. Generated from `changes/`;
do not edit by hand.

## 1.2.0 — 2026-11-01

- The dictionary now carries **every** pronunciation, not one per word: 133,971 readings of 124,926 words, 8,383 of them with more than one. `fire` measures as one syllable or two and `read` as *reed* or *red*, and the metre picks the reading that lands on the count the form asks for. The derivation is reproducible — `python3 scripts/build-dict.py path/to/cmudict.dict` — and the file is smaller than the one it replaced. Two tabs on the same journal now tell each other when one of them saves, so neither silently reverts the other.

## 1.1.0 — 2026-11-01

- Five more forms (blank verse, terza rima, rubaiyat quatrain, tanka, limerick) and a generic checker: a form is now data — line count, syllable pattern, foot, tolerance, scheme — so the next one is a dozen lines rather than a new branch. The metre message names the foot that broke and which way the beat falls there.
- The journal gained import, a line diff between versions, rename, copy and a one-level undo on delete. Drafts now live in IndexedDB rather than localStorage, so a journal of versions is no longer up against a 5 MB ceiling. In-page dialogs replace `prompt`, `confirm` and `alert`, which the Android WebView suppresses.
- A ghazal written in Devanagari or Gujarati is now measured in **matra**, not in English phonemes: every line of a couplet must share the same count, which is the practical test of a shared beher. The count is shown in the gutter and the script is named under the form. Words in any script are now split correctly — the word breaker kept only A-Z, so a Hindi line arrived as no words at all.
- The app installs itself: a service worker caches the six files once, so afterwards it opens from an icon with the network off. The page is served network-first and the cache name is bumped on every release, so a new build is never hidden behind a stale cache. `node scripts/build-single.mjs` also folds the whole workshop into one 2.3 MB HTML file.
- The rolling release now describes itself: the app's own icon, a table of the three builds with sizes and SHA-256 digests read back from the release that was just published, and the local badges. Generated by `scripts/release-notes.sh`, never typed.
- Words whose pronunciation changes their meaning — `record`, `present`, `wind`, `read`, `blessed`, `learned` — keep both readings, and the metre picks the one the line asks for, so "the blessed rain" is measured as three syllables or four depending on the form.
