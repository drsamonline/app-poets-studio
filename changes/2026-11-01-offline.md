The app installs itself: a service worker caches the six files once, so afterwards it
opens from an icon with the network off. The page is served network-first and the cache
name is bumped on every release, so a new build is never hidden behind a stale cache.
`node scripts/build-single.mjs` also folds the whole workshop into one 2.3 MB HTML file.
